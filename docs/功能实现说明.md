# 功能实现说明

> 状态标识：✅ 已实现　🟡 部分实现　⬜ 规划中

## 1. 当前完成度

初始化脚手架打通了一条最小可用链路：

```text
登录页 → POST /api/auth/login → JWT → 定时任务列表/新建/编辑/启停/删除
```

- 后端可编译、可启动（依赖 MySQL；Redis 承载登录失败计数与令牌黑名单，故障时认证链路自动降级）；
- 前端可独立启动，开发环境通过 Vite 代理访问 `/api`；
- 提供 Docker Compose 一键启动 MySQL / Redis / 后端 / 前端；
- 前端业务页面已全部落地：除登录与任务管理外，其余模块使用 `frontend/src/mock` 的演示数据，可在浏览器中完整走通界面流程。

## 2. 已实现功能

### 2.1 认证与用户（B1 部分）

| 功能 | 实现 |
| --- | --- |
| 账号密码登录 | `POST /api/auth/login`，BCrypt 校验 |
| JWT 签发 | HS256，默认有效期 12 小时，密钥由 `JWT_SECRET` 注入 |
| 密钥校验 | `JWT_SECRET` 必填且至少 32 字节；非 dev 环境未配置时启动失败，开发默认密钥仅在 `application-dev.yml` |
| 令牌刷新 | `POST /api/auth/refresh`，旧令牌未过期时签发新令牌并立即加入黑名单，返回 `{ token, expiresIn }`（分钟） |
| 注销 | `POST /api/auth/logout`，幂等；有效令牌按剩余有效期加入 Redis 黑名单 |
| 登录限流 | 同一用户名 5 次失败锁定 5 分钟，成功登录清除计数；Redis 故障时降级为进程内计数，不阻断登录 |
| 跨域白名单 | `CORS_ALLOWED_ORIGINS` 逗号分隔，默认本地 5173 两个来源，禁止 `*` 与凭据组合 |
| 请求鉴权 | `JwtAuthenticationFilter` 解析 Bearer Token 写入 SecurityContext |
| 当前用户 | `GET /api/auth/profile` |
| 统一异常 | 未登录/无权限/业务异常/参数校验均返回统一 `Result` |
| 前端登录态 | Vuex + localStorage，路由守卫拦截未登录访问 |
| 邮箱验证码与注册 | Mock 模式提供 `/auth/email-code`、`/auth/register`，账号保存在浏览器本地，仅用于演示 |
| 管理后台登录 | 独立入口与会话（`lingxi-admin-session`），演示账号 `admin / Admin@123` |

初始化阶段后端未实现：注册、找回密码、管理员强制下线/多端会话管理、验证码、第三方登录、管理员角色鉴权。

### 2.2 定时任务（B7 部分）

| 功能 | 实现 |
| --- | --- |
| 任务列表 | `GET /api/agent/tasks`，支持 `page` / `size`（默认 1/20，最大 100），响应仍为数组，仅返回当前用户任务 |
| 新建任务 | `POST /api/agent/tasks`，默认云端、Asia/Shanghai、每天 09:00、50 轮 |
| 更新任务 | `PUT /api/agent/tasks/{id}`，字段为空表示不修改 |
| 启停任务 | `PATCH /api/agent/tasks/{id}/status` |
| 删除任务 | `DELETE /api/agent/tasks/{id}`，逻辑删除 |
| 归属校验 | 非属主操作返回 `7002` |
| 参数校验 | 频率、cron 表达式、时区、weekDays（1-7）、间隔、时间、轮次、抖动均有服务端校验，非法返回 `7004` |
| 并发冲突 | 更新/启停时若任务状态已被其他请求修改，返回 `7005` |

任务字段中的 `run_count`、`last_run_at`、`next_run_at`、`last_output` 已预留，调度器接入后更新。

### 2.5 列表分页与表格规范

- 所有数据表格默认每页 10 条，统一使用 `components/TablePager.vue`；
- 筛选条件变化时回到第 1 页，数据量减少时自动回退到最后一页；
- 固定列统一使用不透明背景，避免与相邻列文字重叠；
- 卡片网格类列表（首页精选、技能、连接器等）不分页，保持沉浸式浏览。

### 2.6 工程能力

- 统一响应、全局异常（请求体不可读 `4001`、参数类型不匹配 `4002` 与系统错误 `5000` 区分）、Swagger/Knife4j 文档；
- MyBatis-Plus 分页插件（`maxLimit=100`）、逻辑删除；
- RedisTemplate JSON 序列化配置，以及登录失败计数与令牌黑名单能力；
- 初始化 SQL（幂等）与演示账号 / 演示任务；
- 全站列表分页、固定列不透明背景与深色主题适配；
- Dockerfile（前后端多阶段构建）与 docker-compose；
- 中英文 README、架构/接口/数据库/开发文档。

### 2.7 前端健壮性

- 缓存读取：`localStorage` 数据解析失败或类型不符时回退默认值，避免脏数据导致页面白屏；
- 管理员会话：管理员令牌独立保存，不覆盖用户端 token；
- 401 处理：用户端自动调用 refresh 并重放原请求一次，失败后清理登录态；
- 计时器：页面卸载时清理 `setInterval` / `setTimeout`，避免重复请求与内存泄漏；
- 积分账本：先持久化任务/记录再扣费，落盘失败时不产生消费流水；
- 兑换码：兑换与领取时校验有效期，过期兑换码/优惠券不可用；
- 登录回跳：仅接受站内相对路径，拒绝 `//evil.com` 等开放重定向；
- 后台入口：隐藏路径只降低被发现概率，不构成安全边界。

## 5. 已知限制

- 调度器未接入，任务不会自动执行；`next_run_at` 暂为空；
- JWT 校验保持无状态，注销/刷新通过 Redis 黑名单使旧令牌失效；管理员强制下线与多端会话管理仍未实现；
- Redis 故障时登录限流降级为进程内计数，多实例部署下计数不共享；
- 初始化 SQL 只覆盖 3 张表，其余表随模块迭代新增；
- 未实现多租户/组织隔离，当前按单用户任务归属校验；
- 除登录与任务管理外，业务数据均为浏览器本地演示数据，清空缓存会恢复默认示例，不能作为真实业务数据；
- 管理后台为前端演示会话，路由守卫只能拦截界面访问，不能替代后端鉴权；
- 管理后台与用户端共用同一构建产物，隐藏路径仅降低被发现概率，不构成安全边界；
- 演示账号密码固定，部署前必须修改。
